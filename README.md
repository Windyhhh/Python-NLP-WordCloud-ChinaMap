# 🐍 Python NLP WordCloud ChinaMap | Python 爬虫 + NLP 词频 + 中国地图词云

> **Complete pipeline: web crawler → NLP word frequency analysis → China map word cloud visualization. Scrape Chinese text data, perform jieba segmentation, count word frequencies, generate word clouds overlaid on China map.**
>
> 完整流水线：网络爬虫 → NLP 词频分析 → 中国地图词云可视化。爬取中文文本数据，jieba 分词，统计词频，生成叠加在中国地图上的词云。

---

## 🌟 Features | 核心特性

- **Web Crawler** — Scrape Chinese text from websites
- **Jieba Segmentation** — Chinese word segmentation
- **Word Frequency** — TF/TF-IDF analysis
- **China Map WordCloud** — Word cloud shaped like China map
- **Stop Words** — Built-in Chinese stop words list
- **Visualization** — Matplotlib + wordcloud + PIL

---

## 🚀 Quick Start | 快速开始

```bash
pip install requests beautifulsoup4 jieba wordcloud matplotlib pillow numpy

# Run full pipeline
python main.py

# Generate word cloud only
python wordcloud_china.py
```
